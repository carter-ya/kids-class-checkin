# 小小上课日历

家庭成员可以一起记录孩子的课程。首页显示各门课本月上了几节、当前周期还剩几节。点课程卡查看月历或每月课时，点「管理课程」添加课程、改名、续课或删除。每门课程每天可打卡一次。课程的日期、课时和周期可分别设置。

## 第一次使用

1. 在登录页点「还没有账号？去注册」，选择带头像的家庭称呼，输入账号并确认两次密码。注册密码为 8–16 个字符，可含特殊符号。注册后自动登录，可选择创建家庭，或输入家人的邀请码加入已有家庭。跟着小兔指向的按钮可以直接操作，也可以点「看下一处」或「跳过」。
2. 首次添加课程时，小兔会跟随正在填写的项目提示。保存后会接着引导打卡和查看月历，可以随时跳过。点「今天上课啦」打卡，在月历里点日期可以补记或撤销。
3. 家人分别注册账号后，任意成员都能打开右上角家庭菜单，点「管理家人」→「添加家人」，输入对方账号并选称呼。添加会立即生效。对方刷新手账即可看见加入的家庭。在「管理家人 → 邀请家人加入」可分享或复制邀请链接，也可复制 6 位短码。收件人打开链接，登录或注册后确认加入。邀请有效期 7 天，成员退出或被移除后，当前家庭已分享的邀请会失效。电脑可用鼠标悬浮打开菜单，手机可轻点家庭名。
4. 同一个账号可以创建或加入多个家庭。称呼按家庭设置，支持八种带头像的预设，也可自定义。在成员旁点「编辑」可改称呼。创建人可以移除其他成员，其他成员可以自行退出。
5. 右上角家庭菜单中的「操作记录」显示当前家庭最近的操作，最多 100 条，最新的排在最前面。每条包含操作者当时的称呼、账号和具体操作。课程删除或成员退出后，历史仍会保留。同一菜单中的「新手引导」可以重新开始带路。

## 本地运行

使用 Node.js 22.13 或更新版本，在项目目录运行：

```sh
npm ci
npm run db:local
npm run dev
```

浏览器打开 http://localhost:8787 。运行 `npm test` 会使用独立的临时 D1 测试迁移、家庭协作、访问权限、历史、课程统计和并发打卡。

## 数据与部署

数据库绑定名为 `DB`。升级前备份现有 D1，再应用迁移。每个旧账号会得到独立家庭，已有课程、周期、打卡日期和打卡时间随账号迁入。旧打卡以原账号显示。旧版未保存的撤销或成员操作没有历史可迁移。

部署到自己的 Cloudflare 账号时，先运行 `npx wrangler login`。首次部署可用 `npx wrangler d1 create kids-class-checkin` 创建数据库，将返回的 `database_id` 填入 `wrangler.jsonc`。升级已有部署时使用原数据库。运行 `npm run db:remote` 应用迁移，然后运行 `npm run deploy`。自助注册无需管理员密钥。

`CLASS_TIME_ZONE` 默认为 `Asia/Shanghai`，按上课地点判断当天日期。会话使用 HttpOnly Cookie，有效期 30 天，退出仅撤销当前设备的会话。注册和登录分别按来源 IP 限制尝试次数。

## 接口

写请求使用同源 JSON。注册、登录成功后设置会话 Cookie。家庭读写请求使用 `X-Family-Id` 指定家庭，省略时默认使用自己的第一个家庭。服务端按会话校验成员身份，记录真实操作者。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| POST | /api/register | 传入 username、password 和可选的 role，注册并登录 |
| POST | /api/login、/api/logout | 登录或退出 |
| POST | /api/guide | 记住当前用户已完成或跳过引导 |
| POST | /api/families | 传入 name、role 创建新家庭 |
| POST | /api/invitations | 获取当前成员的 6 位短码、邀请路径及到期时间 |
| GET、HEAD | /invite/:token | Worker 直接返回包含邀请人、家庭名、摘要和封面图的 Open Graph 与 Twitter Card 标签，供聊天平台抓取 |
| POST | /invite/:token | 登录后确认加入，跳转到对应家庭手账 |
| POST | /api/families/join | 使用家庭邀请码 code 和可选称呼 role 加入家庭 |
| GET | /api/members | 查看当前家庭成员及可切换的家庭 |
| POST、PATCH、DELETE | /api/members | 按 username 添加成员、改称呼或移除成员，添加和改称呼时传入 role |
| GET | /api/history | 当前家庭最近的最多 100 条操作，按新到旧排序 |
| GET | /api/calendar | 家庭列表、课程和周期、本月统计、打卡日期及对应账号 |
| PUT、DELETE | /api/checkins/YYYY-MM-DD | 补记或撤销已选周期内的一次上课 |
| POST | /api/courses | 传入 name、first、last、total 创建课程和首期 |
| PATCH、DELETE | /api/courses/:id | 改名或删除课程及其周期、打卡 |
| POST | /api/courses/:id/cycles | 传入 first、last、total 续课，返回 cycleId |

日历与打卡接口可用查询参数 `?cycle=周期ID` 选择周期。起止日期格式为 YYYY-MM-DD，包含首尾两天。
